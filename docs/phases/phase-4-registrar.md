## สรุปสั้น

เจ้าหน้าที่ทะเบียนเห็นคิวคำขอที่ระบบตัดสินเองไม่ได้ พร้อมเวลารอและไฮไลต์ SLA · เปิดหน้าพิจารณาเพื่อดูข้อมูลคำขอ เหตุที่เข้าคิว และระเบียนที่จับคู่ได้ · ค้นหาระเบียนเอง · อนุมัติ (สร้าง snapshot + ลิงก์ + อีเมล) หรือปฏิเสธพร้อมเหตุผล · จดหมายเหตุภายใน · ค้นหาและดูระเบียนนักศึกษา · อนุมัติ/ระงับหน่วยงาน ทุกการกระทำบันทึก audit

## การตัดสินใจเชิงออกแบบ

- **ข้อความทั้งหมดแปลฝั่ง server** แล้วส่งให้ client component เป็น string — ไม่ต้องส่ง messages ทั้งไฟล์ไปที่เบราว์เซอร์
- **ตัวกรอง/เรียง/แบ่งหน้าทำฝั่ง server ผ่าน URL** — แชร์ลิงก์คิวที่กรองแล้วได้ ใช้งานได้แม้ JavaScript ยังโหลดไม่เสร็จ · TanStack Table ใช้จัดคอลัมน์และแสดงผล
- **เจ้าหน้าที่อนุมัติระเบียนที่ไม่ใช่ GRADUATED หรือติดธงได้** แต่ระบบแสดงคำเตือนก่อนกด เพราะการตัดสินขั้นสุดท้ายเป็นของเจ้าหน้าที่
- **ข้อมูลส่วนบุคคลใน audit:** บันทึกการดูเลขเต็ม การค้นหา และการเปิดดูระเบียน โดยไม่เก็บเลขบัตร คำค้น หรือเนื้อหาโน้ตลง log

| 6 | ไม่ระบุค่า SLA | **env ใหม่** `REVIEW_SLA_HOURS=24` (เตือนที่ 75%) | ดีไซน์ระบุ SLA 24 ชั่วโมง · ปรับได้ตามนโยบายฝ่ายทะเบียน |
| 7 | ดีไซน์หน้าคิว/หน้าพิจารณา | **ยังไม่ทำ:** ปุ่ม Export Excel (F-RPT-07), checkbox เลือกหลายแถว, กระดิ่งแจ้งเตือน (F-NOT-05), ตัวเลขจำนวนคิวบนเมนูข้าง, สถานะการส่งอีเมลในไทม์ไลน์ (ต้องใช้ `EmailLog` Phase 9) · ปุ่ม "ตัวกรองเพิ่มเติม" แสดงเป็นแถวตัวกรองแทน | อยู่ใน Phase อื่น หรือไม่มีการกระทำแบบหลายแถวใน spec |
