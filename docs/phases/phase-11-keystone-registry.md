## สรุปสั้น

ระบบทะเบียนจริงของมหาวิทยาลัยคือ Keystone Open API ซึ่ง**รูปแบบต่างจากสัญญาที่เราเสนอ** (`registry-api-spec.md`) มาก จึงเพิ่ม client ตัวที่สาม `REGISTRY_CLIENT=keystone` โดยไม่เปลี่ยน client เดิม

- สำรวจ API จริงด้วยสคริปต์ที่พิมพ์เฉพาะชื่อฟิลด์ รูปแบบ และค่าหมวดหมู่ (ไม่บันทึกข้อมูลส่วนบุคคล)
- Keystone **ไม่มี** วันสำเร็จการศึกษา วันสภาอนุมัติ เกียรตินิยม เวลาแก้ไขล่าสุด การแบ่งหน้า และชื่อวุฒิ/คณะภาษาไทยในรายการแบบชุด
- ผู้ใช้เลือกแนวทางทุกข้อ (ด้านล่าง) · กฎ auto-approve ตัดเงื่อนไขวันสภาอนุมัติชั่วคราว และ**กลับไปใช้กฎเดิมเมื่อ API ส่งค่านี้**

## สิ่งที่ทำ

| Sync | หนึ่งหน้า = ระดับ × ปี พ.ศ. (รุ่น `YY1`–`YY3` เพราะรุ่น = ปี 2 หลัก + เทอม 1–3) · ค่าเริ่มต้นรุ่น 653 ขึ้นไป (105 คำขอ) · `KEYSTONE_BATCH_RANGE` ใช้ sync รุ่นเก่าภายหลัง · รุ่นที่ไม่ตรงรูปแบบไม่เก็บ `sourceBatch` · หยุดตาม `hasMore` เท่านั้น · ข้ามระเบียนเดิมด้วย HMAC ของเนื้อหา · เรียก `StudentAcademicRecord` เฉพาะผู้สำเร็จการศึกษาที่เปลี่ยนหรือยังไม่มีรายละเอียด · INCREMENTAL ของต้นทางที่ไม่รองรับทำงานแบบเต็มชุด · งานค้างตรวจจาก `updatedAt` | `sync.service.ts`, `mapper.ts`, `types.ts` |

## ข้อจำกัดที่ทราบ / ส่งต่อ

- **sync เต็มชุดยังไม่ได้ทำ** — ทดลองแค่รุ่น 640–649 (ผู้สำเร็จการศึกษา 1,201 คน ใช้ 12.5 นาที ≈ 0.6 วินาที/คน) · sync จริงควรทำบนเครื่อง UAT/production ไม่ใช่เครื่อง dev เพราะเก็บข้อมูลส่วนบุคคลจริง
- **รุ่นก่อน 653 ยังไม่ถูก sync** — ผู้สำเร็จการศึกษารุ่นเก่าจะค้นไม่พบและเข้าคิวเจ้าหน้าที่จนกว่าจะ sync ด้วย `KEYSTONE_BATCH_RANGE=561-652` (ช่วงนี้มีผู้สำเร็จการศึกษาจำนวนมาก ดึงรายละเอียดนานหลายชั่วโมง)
- **วันสภาอนุมัติ · เกียรตินิยม · สาขาวิชา** ยังไม่มีจาก Keystone (คำถามข้อ 4 ใน gap doc)
- ระเบียนที่ไม่มีเลขบัตร/พาสปอร์ตที่ใช้ได้ (~8% ในรุ่นที่ทดสอบ ส่วนใหญ่ลาออก/พ้นสภาพ) ค้นหาไม่ได้
- ปุ่ม "ดึงข้อมูลใหม่" ใช้ได้เฉพาะระเบียนที่ sync มาแล้ว (ต้องรู้ระดับ + รุ่น)
- รหัสนักศึกษาที่ผู้ใช้กรอก (ลงทะเบียนศิษย์เก่า) เปลี่ยนจาก 10 หลักเป็น **ตัวเลข 8–12 หลัก** ตามข้อมูลจริง · หน้าเจ้าหน้าที่/ปุ่มดึงข้อมูลรับรหัสที่มีตัวอักษรปนได้ (`isRegistryStudentCode`)
- API key อยู่ใน PDF ที่ส่งกันมา — ควรขอ key แยกสำหรับ production และเปลี่ยน key ชุดนี้
