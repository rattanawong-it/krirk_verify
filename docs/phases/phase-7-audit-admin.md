## การตัดสินใจเชิงออกแบบ

- **ค่าตั้งค่าอ่านจากฐานข้อมูลทุกคำขอ** (cache ต่อคำขอด้วย `React.cache`) — ผู้ดูแลบันทึกแล้วมีผลทันทีทุก instance โดยไม่ต้องมี cache invalidation ข้ามเครื่อง
- **หน้าแรกและหน้านโยบายยังเป็น static** — สร้างใหม่ทันทีเมื่อบันทึกค่า (`revalidatePath`) และทุก 5 นาทีเป็นค่าสำรอง
- **anonymise แทนการลบแถวคำขอ** — สถิติรายงาน (Phase 6) ยังนับจำนวน/สถานะ/หน่วยงาน/วันที่ได้ แต่ไม่เหลือข้อมูลที่ระบุตัวบุคคล
- **Audit Log ต้องเก็บนานกว่าหรือเท่ากับคำขอ** (ฟอร์มบังคับ) เพื่อให้ตรวจย้อนหลังการเข้าถึงคำขอได้ตลอดอายุของคำขอ
- **รายการ audit ไม่เก็บข้อมูลส่วนบุคคลเพิ่ม** — การตั้งค่าเก็บเพียง key/ค่า, การจัดการผู้ใช้เก็บเพียงอีเมลของบัญชีเป้าหมาย

## วิธีทดสอบด้วยตนเอง

1. ล็อกอิน `admin@krirk.ac.th` → เมนู **ตั้งค่าระบบ** → ใส่ประกาศหน้าแรก → บันทึก → เปิด `/` เห็นแถบประกาศ
2. **ผู้ใช้ระบบ** → เพิ่มผู้ใช้ → ดูอีเมลเชิญที่ Mailpit http://localhost:8025 → ตั้งรหัสผ่านจากลิงก์ → ล็อกอินได้
3. **Audit Log** → กรอง action / ช่วงเวลา → กด "รายละเอียด" → Export CSV แล้วเปิดใน Excel
4. ทดสอบ retention: ตั้ง "เก็บคำขอไว้" เป็น 1 ปี แล้วแก้ `decidedAt` ของคำขอหนึ่งให้เก่ากว่า 1 ปีผ่าน Adminer (http://localhost:8080) → กด "รัน retention ตอนนี้" → เปิดคำขอนั้นจะเห็นข้อความพ้นระยะเก็บรักษา
5. ตรวจ header: `curl -I http://localhost:3000/`
