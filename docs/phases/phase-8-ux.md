## การตัดสินใจเชิงออกแบบ

- **ไม่เขียนตัวแปลงปี พ.ศ. เอง** — ใช้ปฏิทินของ `Intl` ตาม CLDR เพื่อให้เดือน/ปีย่อถูกต้องตามภาษาไทยทุกรูปแบบ
- **drawer ใช้ Radix Dialog ตัวเดียวกับ dialog อื่น** — ได้ focus trap, ปิดด้วย Esc และ `aria-modal` โดยไม่เพิ่ม dependency
- **skeleton ใช้โครงกลางเดียว** ในทุกพื้นที่ที่มี App shell — หน้าแสดงผลภายในไม่กี่ร้อยมิลลิวินาที การทำ skeleton รายหน้าเพิ่มโค้ดมากโดยผู้ใช้แทบไม่เห็นความต่าง

5. สลับภาษาไทย/อังกฤษในหน้า Audit Log → ปีเปลี่ยนระหว่าง 2569 / 2026

## ข้อจำกัดที่ทราบ / ส่งต่อ Phase ถัดไป

- **Phase 5 (ตรวจสอบแบบชุด), 6 (Dashboard/รายงาน), 9 (Email Log)** ยังไม่มีหน้า — ต้องทำตามข้อกำหนด F-UX (การ์ดบนมือถือ, 44px, แปลครบ) ตอนสร้าง
- **ยังไม่มีการตรวจ accessibility อัตโนมัติ** (axe) และยังไม่ได้ทดสอบกับ screen reader จริง
- **ปุ่มขนาดเล็กบนจอ ≥ sm** (เช่น ปุ่มสลับภาษา 32px) คงตามดีไซน์ — ผ่านเกณฑ์ขั้นต่ำ WCAG 2.2 AA (24px) แต่ต่ำกว่า 44px ที่ spec กำหนดสำหรับมือถือ
